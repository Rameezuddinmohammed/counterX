Before you begin

This page is a reference guide only. It does not configure anything automatically.

S

Shopify Storefront MCP

A per-store, shopper-facing server for catalog search, product details, policy questions, and cart interactions.

No secret required for the documented storefront endpoint
Important: this is not Shopify Admin API access. It cannot replace the Counter Merchant work that needs an installed Shopify app, Admin API scopes, webhooks, draft orders, order finalization, cancellation, and refund verification.
Shopify MCP entry — merge into mcpServers 
"shopify-storefront-dev": {
  "url": "https://counter-dev-store.myshopify.com/api/mcp"
}
R

Razorpay Remote MCP — Test Mode

Useful for inspecting and testing the provider account. It is not a substitute for Counter’s server-side payment adapter, signature verification, webhook processing, or authoritative reconciliation.

Test credentials only
Never use live Razorpay credentials here. Razorpay MCP tools may be capable of creating or changing payment objects. Counter’s Razorpay pilot path remains human-present Standard Checkout, never unattended payment automation.
PowerShell — create the test token locally 
$keyId = "YOUR_RAZORPAY_TEST_KEY_ID"
$keySecret = "YOUR_RAZORPAY_TEST_KEY_SECRET"
$pair = "${keyId}:$keySecret"
$token = [Convert]::ToBase64String([Text.Encoding]::ASCII.GetBytes($pair))
$token
PowerShell — store token as a user environment variable 
[Environment]::SetEnvironmentVariable(
  "RAZORPAY_TEST_MERCHANT_TOKEN",
  $token,
  "User"
)
Razorpay MCP entry — merge into mcpServers 
"razorpay-test": {
  "url": "https://mcp.razorpay.com/mcp",
  "headers": {
    "Authorization": "Basic ${RAZORPAY_TEST_MERCHANT_TOKEN}"
  }
}
A

AWS MCP — documentation first

Use AWS MCP now for documentation and architecture help. Add AWS credentials only when Counter reaches the infrastructure deployment task.

No AWS credentials required for documentation/skill discovery
Cost warning: AWS MCP itself has no separate charge, but AWS resources it creates or uses can cost money. The planned pilot stack is not guaranteed to fit free-tier limits. Do not provision cloud resources before budgets and least-privilege access are ready.
PowerShell — install uv 
winget install --id astral-sh.uv -e
uvx --version
AWS MCP entry — documentation first 
"aws-mcp-docs": {
  "command": "uvx",
  "timeout": 100000,
  "transport": "stdio",
  "args": [
    "mcp-proxy-for-aws==1.6.3",
    "https://aws-mcp.us-east-1.api.aws/mcp",
    "--metadata",
    "AWS_REGION=ap-south-1"
  ]
}

Final Kiro configuration

Your current workspace configuration is empty, so this complete template can replace it. Fill only the Shopify development-store domain. The Razorpay token stays in the Windows environment, not this file.

Later — do not block local scaffolding

These are required at later Gate A/deployment milestones, not to start Counter’s shared foundation.

Shopify Admin integration

Create a Shopify app, select and prove least scopes, configure webhooks, and collect Client ID/secret plus a secure Admin API authentication method. This is separate from Storefront MCP.

Razorpay provider certification

Configure the human-present Standard Checkout test flow, server-side order creation, webhook secret, authoritative query, refunds, and ownership evidence for the merchant test account.

AWS deployment access

Enable MFA and budgets, then use an IAM Identity Center/SSO or narrowly scoped role. Avoid root and long-lived administrator access keys. Start read-only and review IaC before deployment.

Wallet Gate A

Select a human identity/step-up provider, a Windows secure-key-store implementation, local packaging/update method, and the first supported AI host.
